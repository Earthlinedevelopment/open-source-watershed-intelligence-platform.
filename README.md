# Earthline

## Aquifer Recharging Starts Here

### How can this landscape recharge more water, retain more soil, and become more resilient?

Earthline is an open-source watershed intelligence platform designed to help communities identify opportunities to:

- Recharge Aquifers
- Retain Soil
- Restore Landscapes
- Preserve Landscapes
- Measure Outcomes

## Earthline Principles

💧 Recharge Aquifers

🌱 Retain Soil

🏞️ Restore & Preserve Landscapes

📈 Measure Outcomes
