WHAT EARTHLINE WILL MONITOR
1. TRAFFIC / AUDIENCE
   - Sessions and page views.
   - Entry path and referrer HOST only.
   - UTM source / medium / campaign.
   - Language and timezone.
   - Coarse device capability, viewport/screen buckets, connection class and dark/light preference.

2. SEARCH / COST CONTROL
   - Search requests, success/failure, response time and result count.
   - Guest/account class without recording a raw address or search string.
   - Global/guest/account/rate-limit blocks.
   - Current global search-cap consumption versus the hard daily cap.

3. EARTHLINE ANALYSIS FUNNEL
   - Regional analysis start/success/failure and duration.
   - Property analysis start/success/failure and duration.
   - Jurisdiction and optional coarse 0.25-degree geographic bucket only.
   - Report opens, DATA opens, Swales Explained opens and other explicitly tagged controls.

4. RELIABILITY
   - JavaScript errors and unhandled promise rejections.
   - Error class plus short sanitized message; no private form/search content.
   - Search/backend failures.
   - Analysis failure rate.

5. PERFORMANCE
   - TTFB, FCP, LCP, CLS and INP when supported.
   - Navigation time.
   - Resource count, total transfer bytes and count of resources slower than 1 second; resource URLs are NOT recorded.
   - Long-task count, total duration and maximum duration.
   - Analysis p50 and p95 runtime.

6. CONVERSION / OUTREACH
   - Contact clicks.
   - Donate clicks.
   - Merchandise clicks.
   - Account sign-in/sign-up event counts.
   - No payment-card or payment-detail collection occurs in telemetry.

7. ADMIN OPERATIONS
   - Authenticated Earthline Operations dashboard.
   - 24-hour, 7-day and 30-day views.
   - Event counts, top jurisdictions, top errors and Web Vitals.
   - Search daily use/cap and telemetry daily use/cap.
   - Metrics endpoint is fail-closed to an EARTHLINE_ADMIN_USER_IDS allowlist.

PRIVACY / DATA-INTEGRITY LOCK
Earthline telemetry intentionally DOES NOT store:
- raw street addresses or search text;
- exact GPS coordinates;
- raw IP addresses (guest actor identity is salted one-way hash only);
- account passwords or private credentials;
- email/message bodies;
- report text or user-entered private text;
- full resource URLs that could contain search parameters.

The goal is complete operational visibility, not collection of unnecessary personal data.

COST / ABUSE LOCKS
- Telemetry global cap defaults to 10,000 accepted events/day.
- Per-actor cap defaults to 120 accepted events/minute.
- Browser batches contain at most 30 events.
- Payload limit is 64 KB.
- Raw telemetry retention defaults to 30 days.
- Old raw telemetry is pruned opportunistically.
- All telemetry tables have RLS enabled and no anon/authenticated table access.
- Browser ingestion is through the Edge Function only.

NO THIRD-PARTY TRACKER REQUIRED
The core observability stack is first-party Earthline + Supabase. Google Analytics, Meta Pixel or other advertising trackers are not required for operational monitoring and are not added by this build. This avoids sending Earthline visitor behavior to an advertising network and avoids a new external billing dependency.
