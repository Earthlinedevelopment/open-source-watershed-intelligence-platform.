# Earthline MVP

## Objective

Help communities identify opportunities to:

- Recharge Aquifers
- Retain Soil
- Restore Landscapes
- Preserve Landscapes

## Inputs

- Property
- Address
- City
- County
- State
- Country
- Four GPS Points

## Outputs

- Interactive Map
- Opportunity Rankings
- Funding Matches
- Evidence Matches
- Executive Report

## Pilot Region

Vancouver Island
